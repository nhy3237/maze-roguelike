# 울리는 전리품 — 규칙 명세 (v2b, 2026-11-12)

원본은 `reference/v2b.html`의 `CONFIG`와 `LOGIC START~END` 블록입니다. 이 문서와 코드가 다르면 코드가 맞습니다. 수치는 모두 초(s)·칸(타일) 단위입니다.

## 1. 맵 (25×18, 고정)
- 기호: `#` 벽, `.` 바닥, `S` 입구/탈출, `T` 함정, `u` 기름병, `a/b/c` 유물(싼 것→비싼 것). 원본 배치는 `CONFIG.fixedMap`.
- 구역(`CONFIG.zones`): 시작 방, 지름길A, 우회로A, 연결 통로, 중앙 홀, 지름길B, 우회로B, 깊은 방. 같은 이름의 사각형이 여러 개일 수 있음.
- 구역 단위 거리: 입구→중앙 홀 지름길 15칸/우회로 27칸, 중앙 홀→깊은 방 지름길 13칸/우회로 23칸.
- 플레이어는 입구 바로 옆 바닥 칸에서 시작(입구 위 아님). 오른쪽→아래→왼쪽→위 순으로 첫 바닥 칸.

## 2. 오브젝트 랜덤 (`randomizeObjects`) — 골든 맵과 반드시 일치
- 벽·구역·규칙은 고정, 함정·기름병·유물 위치만 시드로 섞음. 같은 시드 = 같은 배치. 판 시작 때 `seed = Date.now() % 1000000 || 1`, 로그에 남김.
- 함정 개수: 라운드 1 `trapPlan = {지름길A:1, 지름길B:1}`, 라운드 2는 원본 맵의 구역별 개수 `{지름길A:3, 우회로A:1, 지름길B:2, 우회로B:1}`(맵을 행→열로 훑을 때 처음 나온 구역 순서가 곧 RNG 소비 순서). 시작에서 걸어서 4칸 이상, 함정끼리 맨해튼 2칸 이상.
- 기름병 5개: 시작에서 걸어서 5칸 초과, 서로 맨해튼 4칸 이상.
- 유물 3개: 시작에서 걸어서 4칸 이상, 함정·기름병 칸 제외, 거리 오름차순으로 3등분한 구간에서 싼 유물→가까운 구간, 비싼 유물→먼 구간에서 하나씩. 유물끼리 가능하면 6칸 이상. 순찰 지점 3곳 모두에서 걸어서 `minGuardDist=4` 이상인 후보가 9개 이상이면 그 후보만 사용.
- 전부 걸어서 닿는 칸에만 놓으므로 항상 클리어 가능.
- 검증: `reference/check_maps.js`(6000판), 기준 배치: `reference/golden_maps.json`(라운드 1·2 × 시드 1~20).

## 3. 라운드
| | 라운드 1 | 라운드 2 |
|---|---|---|
| 유물 | 금 간 방울 100 / 봉인의 조각 300 / 울림의 심장석 600 | 녹슨 나침반 150 / 침묵의 인장 400 / 무너진 왕관 800 |
| 함정 | 2개(지름길A 1, 지름길B 1) | 7개(A3 · 우회로A1 · B2 · 우회로B1) |
| 붕괴 시작 | 첫 유물에서 130 | 110 |
| 수호자 기본 속도 | 1.5 | 1.7 |
| 방울류 | 4.5초마다 반경 7 | 4초마다 반경 8 |
| 최대 점수 | 1500 | 2025 |
| 등급 | 1500/1000/500/1 | 2025/1350/700/1 |
- 방울·나침반: 들고 있으면 주기적으로 울려 반경 안 수호자를 부름. 던지면 떨어진 자리에서 4번 더 울림(첫 울림 1초 뒤).
- 봉인의 조각·침묵의 인장: 함정·수호자 피해 1회 방어 후 깨짐(그 점수도 사라짐), 방어 뒤 무적 1.5. 던지면 방어를 잃음, 키로 던질 땐 2초 안에 한 번 더 눌러야 함.
- 심장석·왕관: 점수용.

## 4. 플레이어
- 속도 4.2, 반경 0.3. 입력은 WASD, 대각선은 정규화. 벽에 막히면 모서리 보정(앞 칸이 열려 있으면 세로/가로 중앙으로 미끄러짐).
- 줍기/탈출: E 또는 클릭. 거리 `interactRange 0.95`(E), `mouseRange 1.9`(클릭). 횃불로 한 번 비춘(`seen`) 유물만 클릭으로 주울 수 있고, 한 번 본 자리는 기억함.
- 던지기: 우클릭 = 가장 싼 유물, 1/2/3 = 값 낮은 순 슬롯. 최대 6.5칸, 벽에서 멈춤. 착지 소음 반경 9. 던진 유물은 바닥에 남아 다시 주울 수 있음(위험·붕괴는 그대로).
- 사망: 소지 유물 전부 잃고 0점. 탈출: 소지 점수 × 배율 `[1,1,1.25,1.5]`(소지 0·1·2·3개).
- 위험 단계 = 처음 줍는 유물 수(최대 3). 되찾기는 단계 불변.

## 5. 횃불·기름
- F 켜기/끄기. 끄는 건 즉시, 켜는 데 1.0초, 켜지는 순간 반경 5 소음. 사방 반경 3.2칸(벽에 막힘). 꺼진 상태는 발밑 0.7칸만.
- 기름 최대 18(시작 18), 켜져 있는 동안 소모. 기름병을 밟으면 +10(최대 18), 맵에 5개. 0이면 꺼짐.
- 8초 넘게 켜 두면 불빛 노출: 반경 40 소음 + 잠든 수호자도 깨움. 켜 둔 채면 8초마다 반복.
- 횃불 없이도 5칸 안(벽에 안 가림) 유물은 작게 반짝임.

## 6. 함정
- 대기 → 경고 1.0 → 작동 0.7 → 휴식 → 대기. 위험 단계 L별 대기 `[1.0,0.9,0.8,0.6]`, 휴식 `[2.2,1.6,1.1,0.7]`. 함정마다 시작 위상이 1.1초씩 어긋남(인덱스 × 1.1).
- 작동 중 밟으면 피격(방어 유물이 있으면 막고 깨짐).

## 7. 수호자 (1마리)
- 상태: dormant(석상) → patrol → alert → investigate(추격) → (도착 후 linger) → patrol. 함정에 걸리면 stunned 4.0(방어로 잡을 때 2.5), 풀린 뒤 2.0초 함정 면역.
- 깨어나는 때: 첫 유물을 줍는 순간(또는 불빛 노출).
- 순찰 지점 [행,열]: (9,10) 석상 자리 → (9,12) → (4,12) 순환.
- 소리: 움직일 때 발소리 반경 `1.0 + 1.5×소지 수`(멈추면 0), 횃불 켜는 소리 5, 던진 유물 9, 방울 울림 반경, 불빛 노출 40. 반경 안의 patrol 상태 수호자는 alert로 전환(`alertTime 1.8`, 속도 1.0), 이후 investigate로 소리 난 칸까지 BFS 최단 경로 이동. 목표 칸에 도착하면 2.5초 둘러본 뒤 순찰로.
- 불빛 발견: 횃불이 켜져 있고 수호자가 6칸 안이며 벽에 안 가리면, patrol이었다면 alert(경계 시간 절반 0.9)로 바뀌고 목표를 내 현재 칸으로 갱신. 보이는 동안 매 틱 갱신 → 곧장 추격. 횃불을 끄면 마지막 목표 칸까지만 가서 둘러보고 돌아감.
- investigate 속도 = 기본 속도 + 0.45×소지 수 + 0.7 (라운드 1: 2.2/2.65/3.1/3.55, 라운드 2: 2.4~3.75). 플레이어 4.2.
- 잡기: 1.1칸 안에 들어오면 멈춰 0.55초 손을 뻗음. 그 안에 1.1칸 밖으로 벗어나면 피함(다시 추격), 아니면 피격.
- 표시: 4칸 안이면 어둠 속에서도 실루엣, 6.5칸 안이면 화면 가장자리 붉게 뜀·심장 소리.

## 8. 붕괴
- 첫 유물을 처음 줍을 때 시작. 이후 처음 줍는 유물마다 −30초(획득 직후 남은 시간이 15초 아래로 내려가지는 않음). 30초·10초 남으면 알림. 0이면 매몰 사망.

## 9. 로그 (유지할 것)
- 이벤트 로그(획득·던짐·수호자 상태·사망 원인)와 1초 간격 수호자 기록(거리·상태·목표·내 구역)을 판 끝 화면에 보여 주고 복사할 수 있어야 함. 첫 줄에 라운드·시드.
